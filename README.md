Pentominoes iOS Application

9/13/2016

This iPad application is a simple puzzle game for the user to test his or her spacial awareness abilities. The user can select from 5 "boards". Each of the boards has a shaded in area that must be covered with 12 "pentominoes" that the user can move into place, rotate 90 degrees clockwise, and flip along the horizontal axis.

The user can drag any of the pieces onto the board. Once a piece is on the board, the user can single tap the piece to rotate the piece 90 degrees or the user can double tap the piece to flip it along the horizontal axis.

The user also has the option to display a "Hint" for the given board selection. The first press of the hint button provides the user with an image of one piece correctly placed on the board. All subsequent presses of the hint button provide the user with an image of one extra piece correctly placed on the board.

If the user is unable to complete the puzzle, the user has the option to let the application solve the puzzle for the current board automatically by pressing the "Solve" button.

If at any point the user would like to reset his or her placements of the puzzle pieces, the user can press "Reset" to return all of the puzzle pieces to their original positions.

NOTES:

As this was only the second project for my Applications Programming class, there are still plenty of advanced features that are missing from this project. It is also a "one-and-done" puzzle game with no replay-ability.

The professor for the course provided us with the images of the boards and puzzle pieces for us to use.

KNOWN ISSUES:

Whenever a puzzle piece gets flipped along the horizontal axis it will sometimes cause a visual animation glitch that looks strange. I'm not sure if there is a work-around using the animation tools currently in the project.

When the user has completed the puzzle, there is not indication that he or she is correct. There should be something included to congradulate the user (or something) for completing the puzzle.

The process of giving hints could be reworked to allow the user to only use a certain number of hints or to show the hints in a different way (on the board itself?).
